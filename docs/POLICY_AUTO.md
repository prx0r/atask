# POLICY_AUTO.md — auto-answer threshold policy (f-20, PROPOSED not active)

Auto-answer requires ALL: kind ≠ AUTHORIZATION (money never auto),
top-choice P ≥ 0.95, N ≥ 50 same-kind, last 10 unanimous, reversible
action only. First violation returns the kind to confirm-mode for 50
more observations. This policy is PROPOSED — it activates only after
f-19 backtest passes on real volume. Until then, confirm-mode maximum.
